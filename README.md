# Swaroop Mohanty — portfolio

Static portfolio site. No build step is required.

## Publish with GitHub Pages

1. Create a **public** GitHub repository, for example `swaroop-mohanty-portfolio`.
2. Upload the contents of this folder to the repository root (including `.nojekyll`).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. When GitHub Pages finishes deploying, use its HTTPS site address. Enable **Enforce HTTPS** in the Pages settings when that option appears.

All image, document, stylesheet, and script references are relative, so they work from a GitHub Pages project URL as well as a custom domain.

## Public content

The portfolio includes contact details, social links, photos, a downloadable resume, certificates, and student project documents. Review those materials before making the repository public.
